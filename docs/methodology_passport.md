## 2. Тип исследования

Исследование является **количественным**. Основная часть строится на структурированном опросе IT-студентов, где цифровые отвлечения, частота переключения контекста, когнитивная нагрузка и прокрастинация измеряются числовыми показателями и шкалами 1–5.

Для RQ2 дополнительно используется небольшое **контролируемое внутригрупповое сравнение**: один и тот же участник выполняет техническую задачу в сфокусированном условии и в условии со стандартизированными отвлечениями. Это позволяет сравнивать когнитивную нагрузку при более контролируемых условиях.

Исследование не является Mixed-Methods, потому что интервью, тематический анализ и другие качественные методы в текущем плане не используются.

## 3. Гипотезы

| Исследовательский вопрос | H0 | H1 |
|---|---|---|
| **RQ1 — цифровые отвлечения** | Статистически значимых различий в частоте основных типов цифровых отвлечений среди IT-студентов нет. | Некоторые типы цифровых отвлечений встречаются статистически значимо чаще других. |
| **RQ2 — context switching и cognitive load** | Частота переключения контекста и мультитаскинг не имеют статистически значимой связи с когнитивной нагрузкой; в контролируемой задаче CLI не отличается между сфокусированным и прерываемым условиями. | Более частое переключение контекста связано с более высокой когнитивной нагрузкой; в контролируемой задаче CLI выше в условии с отвлечениями. |
| **RQ3 — cognitive load и procrastination** | Когнитивная нагрузка не имеет статистически значимой связи с частотой и выраженностью академической прокрастинации. | Более высокая когнитивная нагрузка связана с более частой и выраженной академической прокрастинацией. |

Основной экспериментальный акцент Task 2 делается на **RQ2**, потому что для него есть реальный baseline и контролируемое условие.

## 4. Матрица переменных

### 4.1. Контролируемая часть RQ2

| Тип | Переменная | Операционализация |
|---|---|---|
| **Independent Variable** | Условие выполнения задачи | `focused` — уведомления отключены и нет несвязанных переключений; `interrupted` — стандартизированные сигналы отвлечения. |
| **Dependent Variable** | Cognitive Load Index (CLI) | Среднее четырёх пунктов по шкале 1–5: mental demand, effort, difficulty maintaining focus, difficulty regaining focus. |
| **Dependent Variable** | Mental fatigue | Самооценка после задачи по шкале 1–5. |
| **Dependent Variable** | Task accuracy | Процент правильных тест-кейсов / ответов. |
| **Dependent Variable** | Completion time | Время выполнения задачи в минутах. |
| **Controlled Variable** | Длительность сессии | 20 минут на каждое условие. |
| **Controlled Variable** | Сложность задачи | Две сопоставимые задачи A/B; порядок меняется между участниками. |
| **Controlled Variable** | Среда | Одинаковая или максимально сопоставимая программная и учебная среда. |
| **Controlled / recorded** | Programming experience | Количество семестров / лет изучения программирования. |
| **Controlled / recorded** | Sleep quality | Продолжительность и субъективное качество сна перед задачей. |
| **Controlled Variable** | Порядок условий | Counterbalancing: часть участников начинает с focused, часть — с interrupted. |

### 4.2. Опросная часть

В опросе цифровое поведение **измеряется, а не назначается исследователем**, поэтому эти показатели корректнее рассматривать как measured predictors.

| Роль | Показатели |
|---|---|
| **Measured predictors** | Частота context switching, background multitasking, частота мессенджеров, уведомлений, browser/IDE switching. |
| **Outcomes** | CLI, Procrastination Index (PI), mental fatigue, unrelated-task switching. |
| **Controls** | Academic motivation, task difficulty/importance, deadline proximity, sleep, overall workload, programming experience. |

## 5. Метрики и Baseline

### Primary Metric

**Delta CLI = CLI(interrupted) − CLI(focused)**

Это главный показатель для контролируемой части RQ2. Положительное значение означает, что субъективная когнитивная нагрузка выше в условии с отвлечениями. Статистическая проверка выполняется парным t-test, если распределение разностей приемлемо, иначе — Wilcoxon signed-rank test. Порог значимости: **alpha = 0.05**.

### Дополнительные метрики

- **Context Switch Rate** — число переключений внимания в час.
- **Spearman rho** — связь между частотой переключений и CLI, а также между CLI и PI.
- **Task accuracy** — процент корректного выполнения задачи.
- **Completion time** — время выполнения задачи.
- **Effect size** — парный Cohen's d для оценки практической величины различия.

### Guardrail Metrics

Guardrail-метрики в нашем исследовании относятся не к CPU/RAM, а к **качеству данных и измерений**:

- доля пропущенных значений в тестовом пайплайне не выше **10%**;
- значения шкал Лайкерта должны находиться в диапазоне **1–5**;
- дубликаты `participant_id` в опросе не допускаются;
- для многопунктовых индексов CLI и PI ориентир внутренней согласованности — **Cronbach's alpha ≥ 0.70** на основном наборе данных.

### Baseline

**B0 — Focused Condition:** 20-минутная техническая задача при отключенных уведомлениях и без несвязанных переключений.

**C1 — Interrupted Condition:** сопоставимая 20-минутная задача со стандартизированными сигналами, которые требуют краткого переключения внимания.

Один и тот же участник проходит оба условия, поэтому он фактически служит собственным baseline. Порядок условий чередуется для снижения эффекта тренировки и усталости.

## 6. Воспроизводимость Task 2

Репозиторий содержит:

- `requirements.txt` с точными версиями зависимостей;
- `configs/analysis_config.json` с параметрами эксперимента и путями;
- `src/main.py` — исполняемый тестовый пайплайн;
- `data/sample/` — синтетический микро-сэмпл для проверки запуска до массового сбора данных;
- `results/sample/` — автоматически создаваемый результат тестового запуска;
- `.gitignore` — исключает `.venv`, кэш, логи и реальные participant-level данные;
- `LICENSE` — MIT для исходного кода.

**Важно:** значения из `data/sample/` синтетические и используются только для проверки работоспособности. Они не являются результатами исследования.
