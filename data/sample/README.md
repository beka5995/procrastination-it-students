# Sample Data

This folder contains **synthetic test data only**. The rows are not real research participants and must not be reported as empirical findings.

Files:
- `questionnaire_sample.csv` — 8 synthetic questionnaire rows used to test the survey-analysis pipeline.
- `controlled_task_sample.csv` — 8 synthetic rows (4 paired participants × 2 conditions) used to test the focused-vs-interrupted comparison.

The purpose of these files is to verify that the Task 2 pipeline runs before real data collection in Week 7.
